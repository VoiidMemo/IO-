# IO 映射生成器

参照《IO映射工具.xlsx》的映射规则，自动生成 PLC IO 映射语句的小工具。

## 映射规则

| 类型 | 方向 | 生成语句 |
|------|------|----------|
| I点 | 物理输入 → 全局DB | `"全局".变量名 := "变量名";` |
| Q点 | 全局DB → 物理输出 | `"变量名" := "全局".变量名;` |

## 使用方法

**无需 Python 环境**：直接双击 `IO映射生成器.exe`。

1. 选择 IO 类型：【1】I点（输入）/【2】Q点（输出）
2. 粘贴变量名（支持多行、空格、逗号混合分隔，回车留空行结束）
3. 自动生成映射语句 → 复制到剪贴板，去博途直接 Ctrl+V
4. 同时追加保存到同目录 `IO映射输出.txt`（带时间戳，方便积累归档）

启动时可自定义全局 DB 名称，直接回车默认 `"全局"`。

## 特性

- 自动去重、自动清理误粘贴的引号和空白
- 剪贴板一键复制（Windows 自带 clip 命令）
- 输出文件固定在 exe/脚本同目录，带时间戳追加记录

## 文件说明

| 文件 | 说明 |
|------|------|
| `IO映射生成器.py` | 源码（Python 3，纯标准库零依赖） |
| `IO映射生成器.exe` | PyInstaller 打包版（约 8MB，免环境直接运行） |
| `IO映射工具.xlsx` | 映射规则参照表（原始需求） |

## 重新打包

```bash
pip install pyinstaller
pyinstaller --onefile --console --name IO映射生成器 IO映射生成器.py
```

> 注意：打包后 `__file__` 指向临时解压目录，脚本内已用 `sys.frozen` 判断并改用 `sys.executable` 取 exe 所在目录。
